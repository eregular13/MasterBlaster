# Authorization & Professional Use Policy

MasterBlaster is a **professional security assessment control plane** for authorized penetration testing, application security testing, and bug bounty program work.

## Authorized Use

1. **Written authorization required** — Every engagement must have a signed rules-of-engagement (ROE) document defining scope, timing, contacts, and escalation procedures.
2. **Scope-bound testing** — Targets must match authorized scope patterns. Out-of-scope requests are blocked at the policy layer.
3. **Human approval** — Operators approve MCP deployments. Approvals are logged with timestamps and decision records.
4. **Audit trail** — All jobs, evidence, and exports are recorded for client deliverables and internal QA.

## Client Deliverables

Reports generated by MasterBlaster are **assessment findings documents**, not compliance certifications. Final attestation remains the responsibility of the consulting firm and client stakeholders.

## Operator Responsibilities

- Verify ROE documentation before starting any engagement
- Protect client data and evidence packages per contractual confidentiality terms
- Use professional judgment when interpreting automated findings
- Disclose tooling limitations and manual validation requirements in client reports

## Prohibited Use

- Testing systems without explicit authorization
- Exceeding agreed scope or rate limits
- Misrepresenting automated output as manual expert analysis without disclosure

Accept this policy in the application before accessing assessment features.
