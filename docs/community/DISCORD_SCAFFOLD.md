# MasterBlaster Community Discord (Scaffold)

## Server structure

| Channel | Purpose |
| --- | --- |
| `#announcements` | Releases, security advisories |
| `#general` | Community discussion |
| `#dev-grok` | `grok/masterblaster` development |
| `#plugins` | Marketplace submissions and reviews |
| `#security-review` | Policy, ADR, and pen-test pack discussion |
| `#showcase` | Simulator demos and workflow drafts |

## Roles

- `@maintainer` — merge rights on sensitive paths
- `@reviewer` — plugin and ADR review
- `@operator` — assessment teams using the simulator
- `@community` — read/participate

## Bot commands (future)

- `!mb phases` — render phase tracker dashboard
- `!mb plugins` — list plugin catalog count
- `!mb ethics` — link to ethics disclaimer
